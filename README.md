## インストール

Rust のツールチェインが必要です（開発時は 1.98.0、edition 2024）。

```bash
git clone https://github.com/itomofumi/stocks_cli.git
cd stocks_cli
cargo build --release
```

バイナリは `target/release/stocks_cli` に生成されます。パスの通った場所へ置くと便利です。

```bash
cargo install --path .
```

## 使い方

```
Usage: stocks_cli [OPTIONS] [SYMBOLS]...
```

| 引数・オプション | 説明 | 既定値 |
|---|---|---|
| `[SYMBOLS]...` | 銘柄コード。空白区切りで複数指定できる（最大20件） | `7203.T` |
| `-r`, `--range` | 取得期間 | `5d` |
| `--no-chart` | グラフを表示しない | — |
| `-h`, `--help` | ヘルプを表示 | — |
| `-V`, `--version` | バージョンを表示 | — |

`--range` に指定できる値は `1d` `5d` `1mo` `3mo` `6mo` `ytd` `1y` `2y` `5y` です。それ以外を渡すと取得前にエラーになります。

### 銘柄コードの書き方

| 種別 | 書き方 | 例 |
|---|---|---|
| 日本株 | 4桁の証券コード + `.T` | `7203.T`（トヨタ）、`6758.T`（ソニー）、`9432.T`（NTT） |
| 米国株 | ティッカーをそのまま | `AAPL`、`MSFT`、`NVDA` |
| 指数 | `^` 始まり | `^N225`（日経平均）、`^GSPC`（S&P500） |
| 為替 | `=X` 付き | `JPY=X`（米ドル/円） |

会社名（`toyota` や `トヨタ`）では指定できません。データ源が日本語の社名を索引していないためです。

### 例

```bash
stocks_cli                      # トヨタを直近5営業日分（既定）
stocks_cli 6758.T               # ソニーを表示
stocks_cli 7203.T 6758.T AAPL   # 複数銘柄をまとめて表示
stocks_cli AAPL -r 1mo          # アップルを1か月分
stocks_cli ^N225 --no-chart     # 日経平均をグラフなしで表示
```

### 終了コード

| コード | 意味 |
|---|---|
| 0 | 全銘柄の取得に成功 |
| 1 | 1銘柄でも失敗（エラーは標準エラー出力へ） |
| 2 | 引数が不正（clap によるエラー） |

エラーは標準エラー出力に出るため、リダイレクトすると正常な結果だけをファイルに残せます。

```bash
stocks_cli 7203.T ZZZZ.T --no-chart > result.txt
```

## 動作

- **データ源** — Yahoo Finance のチャート用エンドポイント。API キーは不要です
- **複数銘柄** — 4件ずつ並列に取得します。表示は指定した順を保ちます
- **タイムアウト** — 接続 5 秒、リクエスト全体 10 秒
- **重複の除去** — 同じ銘柄を複数回書いても1回だけ取得します（大文字小文字は区別しません）
- **移動平均線** — グラフに25日移動平均を重ねます。データが25件そろわない期間（`5d`・`1mo`）では表示されず、その旨を表示します。`3mo` 以上で表示されます
- **色** — グラフは終値を水色、移動平均を橙で描きます。パイプやファイルへ出力するときは色を付けません

### 構成

```
src/
├── main.rs        エントリポイント（引数を読む → 並列取得 → 表示 → 終了コード）
├── cli.rs         コマンドライン引数の定義（clap）
├── stock.rs       アプリ内部で扱う株価の型
├── sanitize.rs    端末へ出力する文字列の無害化
├── yahoo/         株価の取得
│   ├── mod.rs       fetch() — HTTP と、API 形式 → 内部型への変換
│   └── model.rs     レスポンスを受ける構造体（serde）
└── output/        標準出力への表示
    ├── mod.rs       再公開のみ
    ├── summary.rs   サマリーと終値一覧
    └── chart.rs     折れ線グラフ
```

`yahoo` が API の形式を `stock::Stock` に詰め替えて返すため、`output` は Yahoo のレスポンス構造を知りません。データ源を差し替える場合の変更は `yahoo/` の中に閉じます。

### 主な依存クレート

| クレート | 用途 |
|---|---|
| [clap](https://crates.io/crates/clap) | コマンドライン引数のパースと検証 |
| [reqwest](https://crates.io/crates/reqwest) | HTTP クライアント（blocking + rustls） |
| [serde](https://crates.io/crates/serde) | JSON のデシリアライズ |
| [chrono](https://crates.io/crates/chrono) | UNIX 秒から JST への変換 |
| [textplots](https://crates.io/crates/textplots) | ターミナルへの折れ線グラフ描画 |
| [rgb](https://crates.io/crates/rgb) | グラフの線の色指定 |

## 注意

**非公式のエンドポイントを利用しています。** Yahoo 側の仕様変更や遮断により動作しなくなる可能性があります。表示される価格は参考値であり、**投資判断に用いないでください**。
